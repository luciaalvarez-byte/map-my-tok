# Map My Tok

## Descripción

Map My Tok es una aplicación web desarrollada en Python que permite organizar y visualizar en un mapa interactivo lugares descubiertos a través de vídeos de TikTok. A partir de la URL de un vídeo, la aplicación tratará de identificar y geolocalizar el lugar mencionado, permitiendo al usuario almacenarlo, clasificarlo y consultarlo posteriormente.

## Objetivos

- Desarrollar una aplicación web interactiva basada en un mapa.
- Extraer información de vídeos de TikTok a partir de su URL.
- Identificar y geolocalizar automáticamente los lugares mencionados.
- Clasificar los lugares mediante técnicas de Machine Learning.
- Permitir la organización mediante categorías, colecciones, filtros y estados.
- Facilitar el acceso posterior al vídeo original y a la ubicación en Google Maps.

## Plan de trabajo inicial

1. Desarrollo de la estructura básica de la aplicación y del mapa interactivo.
2. Integración de URLs de TikTok y extracción de información.
3. Implementación de la detección y geolocalización de lugares.
4. Incorporación de categorías, colecciones, filtros y almacenamiento de datos.
5. Desarrollo y evaluación del modelo de clasificación.
6. Mejora de la interfaz, pruebas y despliegue de la aplicación.
